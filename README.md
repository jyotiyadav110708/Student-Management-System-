# Student Management System

A simple Student Management System built using C++ based on Object-Oriented Programming and File Handling concepts.

## Features
- Add Student Record
- Search Student Record
- Update Student Information
- Delete Student Record
- File Handling

## Concepts Used
- Classes and Objects
- Functions
- File Handling
- OOP Concepts

## Language Used
- C++

## Purpose
This project was created for practicing Object-Oriented Programming concepts and improving C++ development skills.
